# Personal Portfolio — Muhammad Nadeem

**Live Site:** https://mnadeem131.github.io

## Overview
Personal portfolio built for CS-117 (Applications of ICT) at NUST MCS and customized in VS Code using GitHub Copilot. Features my bio, technical and business skills, CS-117 course labs, education, experience, and an interactive Mini Kali Linux Terminal.

## Tech Stack
HTML5, CSS3, JavaScript, jQuery, Particles.js, Typed.js, Tilt.js, ScrollReveal, Font Awesome, JSON
